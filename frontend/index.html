DOCUMENTATION & TUTORIAL

How to Use Replyer

Follow this step-by-step tutorial to connect your Telegram account, create automated reply rules, and secure your personal account.

1

Get Your Telegram API Credentials

Telegram requires every custom automation to have its own unique API ID and API Hash from the official Telegram developer portal. This guarantees your automation uses your own quota and remains safe.

Quick Instructions:
  1. Open https://my.telegram.org and log in with your Telegram phone number.
  2. Click on API development tools.
  3. Fill in App title (e.g. 'MyReplyer') and Short name (e.g. 'replyer'). Click Create application.
  4. Copy your numeric App api_id and 32-character App api_hash.
2

Connect Your Account

Go to the Account tab in Replyer, enter your phone number (+855 xx xxx xxx), API ID, and API Hash, then click 'Send Login Code'.

Verification Step:
  • Open your official Telegram app to read the 5-digit verification code sent directly by Telegram service notifications.
  • Enter the code in Replyer. If you have Two-Step Verification (2FA password) enabled on Telegram, enter your cloud password as well.
  • 'Verify & Connect'. Your session will be securely encrypted and ready!
3

Creating Auto-Reply Rules

Auto-Reply lets you target all chats globally, or specific private DMs, groups, and channels.

Key Features:
  • Targeting: Use filter chips (DMs, Groups, Channels) or search by name / @username. Selected chats will display a prominent ✓ CHECKED.
  • Trigger Conditions: Choose between 'All incoming messages', 'Specific sender(s)', or 'Message contains keyword(s)'. Keyword matching supports 'Any keyword (OR)' and 'All keywords (AND)' modes.
  • Rotating Replies: Separate multiple reply variations with the pipe '|' character. Replyer will randomly rotate them so replies look completely natural!
  • Delays & Cooldowns: Set delay to 0 for instant realtime dispatch, or add a few seconds delay for human-like timing.
4

Section 04 — Realtime DM Away Reply

Section 04 provides a dedicated away message that ONLY answers when someone sends a private 1-on-1 direct message to your personal account.

Strict Protection Rules:
  • Groups, supergroups, and broadcast channels are NEVER replied to by Section 04.
  • Telegram official service accounts and Telegram bots are completely ignored.
  • Set delay to 0 for instantaneous realtime replies while you are away from your phone.
🛡️

Security & Data Protection

Replyer is built with military-grade privacy and zero data leakage:

  • Bearer Token Authentication: All API requests require an encrypted, tamper-proof Bearer token. No user or hacker can view or modify another user's chats or rules.
  • AES-128 Session Encryption: Telegram sessions and API hashes are encrypted with Fernet AES-128-CBC before touching the database.
  • Strict Admin Verification: The admin dashboard is cryptographically locked strictly to the registered ADMIN_PHONE.
